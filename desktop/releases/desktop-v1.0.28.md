## 修复：Telegram 登录检查

- `tg whoami` 失败时不再直接判定为“账号不一致”，先区分：
  - **网络/VPN/代理不可用**：提示“无法连接 Telegram 验证账号”，Bot 保持运行，每 15 秒自动重试；
  - **未登录**：提示运行 `tg login`，Bot 保持运行并自动重试；
  - **其他未知错误**：显示具体原因，继续重试；
  - **真正登录了不同账号**：停止服务，并明确显示“当前账号（A）与绑定账号（B）不一致”。
- 控制中心新增 **「重试验证」** 按钮，可立即重试；自动重试期间按钮显示「正在验证…」。
- 检查超时从 30 秒降为 8 秒，网络不通时不会长时间卡住启动。
- 只有 `EOT10 加密` 开启时才做 `tg` 账号检查；关闭 EOT10 后不再被 Telegram 登录状态阻塞。
- 修复 `CheckTelegramLogin` 不再修改绑定账号；向导步骤仍会自动绑定当前 `tg whoami` 的账号。
- 新增 `desktop/tests/Test-TelegramLoginCheck.ps1`：锁定网络错误、超时、未登录、未知错误的分类。

## 保留 1.0.27 功能

- `/connect`：OAuth + API Key 连接，231 个可连接提供商，搜索、已连接标记、Key 消息自动删除。
- `/create_project`：浏览文件夹、输入名称、创建并进入项目，浏览阶段可取消。
- `/delete_session`、`/delete_project`：删除会话；项目隐藏 + 删除会话并同步到桌面网页，磁盘文件不删除。
- `/open`：所有磁盘/文件夹无限制浏览。
- 13 种语言的文案。
